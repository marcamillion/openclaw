Decisions

Anthropic model discovery, Claude CLI defaults, and Prose's symbolic Haiku selection resolve to claude-haiku-5-5. Preserve explicit model overrides and legacy alias compatibility. Clone the installed SDK catalog entry with documented 1M context, 128K output, reasoning, and 5.5 costs.

The stream adapter removes sampling parameters, uses adaptive thinking when reasoning is requested and disabled thinking otherwise, maps minimal effort to low, preserves explicit output ceilings and forced tools, and supports synchronous or asynchronous source streams.

Tradeoffs

Price all token classes at the long prompt tier above 100,000 combined prompt tokens. The SDK aggregates cache writes: uniform 5m or 1h TTL costs are accurate; a payload with any 1h marker conservatively prices all writes at 1h. Mixed TTL cost may be overstated.
